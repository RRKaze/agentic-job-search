# ADR 0001: V0.1 implementation stack

Date: 2026-09-19

## Status

Accepted

## Context

The repository originally suggested SQLite for the first persistence layer. The latest product direction prioritizes enterprise-transferable tooling for a generalized multi-user product while still keeping the first slice small.

## Decision

V0.1 uses:

- Angular and TypeScript for the frontend.
- ASP.NET Core and C# for the API.
- EF Core with PostgreSQL for persistence.
- xUnit for deterministic domain/application tests.
- Docker Compose for the local PostgreSQL dependency.

The first slice remains manual and inspectable: a user pastes a job, the API normalizes it, evaluates hard eligibility, computes deterministic fit and application priority, persists the result, and the UI displays the recommendation.

## Consequences

This introduces more setup than SQLite, but it better preserves the long-term path toward multi-user persistence, production deployment, and enterprise-style backend experience. V0.1 intentionally avoids extra infrastructure such as queues, Kubernetes, distributed tracing, or automated application submission until product behavior justifies them.
