# V0.1 vertical slice

## Goal

Create the smallest usable Agentic Job Search workflow:

1. Maintain a basic candidate profile with verified evidence.
2. Manually add a job description or URL.
3. Normalize key job fields.
4. Evaluate hard eligibility.
5. Score job fit separately from application priority.
6. Explain the recommendation.
7. Persist the job and evaluation.
8. Display the result in the UI.

## Explicit non-goals

- Automated job discovery.
- Automated application submission.
- Resume rewriting.
- LLM-based semantic scoring.
- Advanced identity features such as social login, password recovery, and organization accounts. Basic account isolation was added after the original V0.1 slice.

These remain part of the longer roadmap, but V0.1 should prove the stateful workflow before adding agents or automation.

## First workflow

```text
Paste job
  -> normalize job
  -> load candidate profile
  -> run deterministic eligibility and scoring
  -> persist job + evaluation
  -> display recommendation
```

## Evidence rule

The seeded candidate profile only contains evidence from the repository's verified project context. Future resume tailoring must cite evidence and must not invent technologies, scope, metrics, ownership, or implementation details.
