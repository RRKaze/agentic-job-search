# Two-week daily-use pilot

Start after owner registration is closed and a hosted backup has been restored successfully. Use the application from desktop and an installed phone PWA.

- Day 1: save and evaluate a real opportunity, update the profile, and move a job into Applications.
- Daily: update status, next action and notes; confirm changes survive refresh and phone/desktop switching.
- Weekly: take an off-site backup and review provider usage. Record cold-start duration and failed requests by correlation ID.
- After a deployment: confirm saved data and the current session survive, and accept the PWA refresh prompt.
- Before finishing: restore a recent backup into an isolated database and verify representative workflows.

For each issue, record date, device/browser, steps, expected behavior, actual behavior, and severity. Keep job descriptions, resume text, evidence, credentials and personal details out of public issues. Track scoring disagreements privately with the evaluation version and reason.

At the end of two weeks, prioritize repeated issues that block daily work. Use this evidence to decide the next product slice; semantic scoring and resume tailoring remain later milestones.
